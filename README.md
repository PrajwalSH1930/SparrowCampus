# 🏫 SparrowCampus – Smart Campus Management App

## 📌 Overview

**SparrowCampus** is an Android-based smart campus management application designed to streamline communication, information access, and administrative workflows within a college campus. The app centralizes important academic and campus-related data, making it easily accessible to students, faculty, and staff.

This project focuses on usability, real-time updates, and scalable backend integration, following modern Android development practices.

---

## 🎯 Key Objectives

* Centralize campus-related information in one platform
* Improve communication between students and administration
* Provide real-time updates and notifications
* Ensure a smooth and intuitive mobile user experience

---

## 🚀 Features

* 🔐 Secure user authentication
* 🏫 Campus information & announcements
* 📅 Academic updates and schedules
* 👨‍🏫 Staff & student directory
* 🔔 Real-time notifications
* 🌐 Online status tracking using Firebase
* 📱 Clean and responsive Android UI

---

## ⚙️ Setup & Installation

1. Clone the repository:

```bash
git clone https://github.com/PrajwalSH1930/SparrowCampus.git
```

2. Open the project in **Android Studio**
3. Let Gradle sync complete
4. Connect a physical device or start an emulator
5. Run the app ▶️
